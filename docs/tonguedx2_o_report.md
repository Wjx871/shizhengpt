# ShizhenGPT-7B-VL：TongueDx2 O 原图测试

测试日期：2026-10-08。使用 O 文件夹全部 48 张原图（实际编号 83–130），没有使用 S。进行了 48 次结构化判读、1 次无图对照、8 次日常舌象描述，共 57 次真实推理。

**本轮可以确认：模型能运行并生成舌象描述，但当前提示下的自动判读可用性不足。结构化回答大多不提供有效判断，存在错误数值和无图视觉断言。与标签的符合程度先按“1=存在对应特征”暂算；由于缺少原始标注规范，不能把它解释为已确认的医学准确率。**

## 推理运行

沿用已部署的官方原始 BF16 权重、K100_AI、eager attention、1003520 最大像素预算和 768 输出 token 上限；关闭采样，seed=42。没有微调、量化、图像增强或手动裁切；官方处理器仍会按像素预算缩放原图。

57/57 次推理成功，均无输出截断。结构化图片判读延迟中位数 8.40 秒；描述模式中位数 22.95 秒。完成后已确认显存释放。

图片 id 在本批标签表中均有唯一对应行，原图哈希已在服务器核对。标签总表与用户指定的微信目录原文件哈希一致。年龄、性别、标签、脏腑、脉象均未输入模型；服务器推理输入包不含标签。

## 结构化判读：回答覆盖率不足

每张要求独立输出舌淡、尖边红、点刺、瘀斑、裂纹、齿痕、厚苔、黄苔，允许 0、1 或 null。

- 384 个特征位置中，只有 **63 个有效 0/1 判断，覆盖率 16.4%**。
- 其余 321 个位置未提供有效判定，包括不确定以及整张格式失败。
- 39/48 张可无损提取全部八项。模型把八个特征键放在 JSON 顶层，没有使用要求的 `features` 嵌套；解析器仅调整结构，没有更改数值。
- **9/48 张输出数值“11”**，违反 0/1/null 要求；没有把 11 猜成 1，整张记为格式失败。编号：100、101、102、104、109、111、117、124、125。

逐项 Precision、Recall、F1、Specificity、Balanced Accuracy 保存于 `metrics.csv`，仅在有效 0/1 预测上计算。部分特征只给出了 1，没有给出 0，少量有效位置的 F1 或 Recall 可能为 1；这不意味着可靠识别。分母为零时指标留空。

## 无图对照：出现无依据的视觉判断

相同结构化提示明确要求“没有图片时八项必须全部 null”。该次记录的 `image_path` 为空、`image_grid_thw` 为 null，确认没有输入图片。

模型却输出 **`TonguePale: 1`**，并写“图片质量低，无法辨识舌体颜色及苔质地”。这是本轮可以直接确认的无图视觉断言及约束不服从。单次对照不能估计这一问题的总体发生率。

## 日常描述模式：固定 8 张的定性观察

使用项目原有舌象描述提示，对固定编号 83、90、97、104、111、118、125、130 补跑，不根据标签选择编号。该提示要求分开写视觉观察、中医解释和不确定信息，因此出现中医解释本身不属于违反提示。

**8/8 回答都将舌苔描述为薄白，并写“无明显裂纹”或“未见明显裂纹”；所有回答都提到轻微或可能的齿痕。** 各图描述有部分差异，如 90 号写淡紫，但整体重复程度较高。这是所选 8 张的现象，不能推算成全部 48 张的自然语言判读准确率。

暂按当前字段解释，这 8 张的标签中 Crack、FurThick 全为 1；83、104、130 的 FurYellow 为 1。描述与该解释存在显著差异，需先确认编码及“轻微裂纹/无明显裂纹”等标注阈值，再由专业人员核验具体图像。

另外，111 号回答写了“舌体活动正常”；单张静态照片不足以确认动态活动正常。111、118 号还描述舌下静脉或络脉，原图是否提供足够可见区域需要人工复核。130 号末尾出现一个 Unicode 替换字符。以上问题均可在原始输出中查看。

## 标签与评估边界

全表有 5109 行，FurThick=1 为 4973 行（97.3%），Crack=1 为 4274 行（83.7%）。本批 48 张分别有 45 张这两项为 1。分布异常集中提示需要核对编码与标注规范，**尚不能据此断言标签错误或编码反转**。

缺少原始 codebook 和专家复核，因此上述标签对照仅为暂定计算；不能确认每项 1 的语义、阈值及标注一致性。全表另有重复 id，但本批 48 个 id 各只有一条标签，没有发生连接扩张。

该批按编号连续取样，不是随机临床样本；未知是否与模型训练集重叠。拍摄条件与舌体在原图中的占比也不同。没有病证真值，因此没有评价疾病、证候、脏腑或脉象诊断准确率。图片质控原因仅为模型自述，没有经过专用舌部质控模块验证。

按暂定编码逐项恒定预测多数标签可得到 72.1% 的全部位置一致率；这是从本批标签事后计算的参照，不能视为独立训练模型的成绩，也不能忽略模型覆盖率差异。

## 验证与后续优先事项

已将 48×8 个 CSV 标签位置逐一与源表核对，独立重算混淆矩阵，结果与汇总一致。57 份原始输出完整保留；运行成功与医学正确性分别报告。

优先确认字段编码和标注标准，再设计提示词对照。当前模型对结构化约束和无图条件的处理需要改善；自然语言输出应保留给专家复核。原图中舌部占比较小时，可另做舌部定位/裁切对照，但本轮没有使用 S。
