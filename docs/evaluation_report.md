# ShizhenGPT-7B-VL：K100_AI 部署与望诊 / 问诊评测报告

日期：2026-10-03（Asia/Shanghai）。这是一轮实际执行的工程探索，未进行临床验证。

## 结论

**部署成功：原始 BF16 权重在 K100_AI 64 GB 上可直接进行图片、文本和图文联合推理。** 正式评测 117/117 次成功，无 OOM、设备错配或输出截断。模型加载后的 PyTorch allocated 显存约 15.45 GiB，正式评测最大 allocated 16.03 GiB，最大 reserved 16.28 GiB。保留了镜像的 DCU 定制 PyTorch，没有量化、安装 flash-attn 或替换系统环境。

**效果结论更谨慎：舌象具备基础描述能力，问诊能追问和表达信息不足，但面诊存在无依据的视觉补全、成像敏感性，图文融合强烈依赖提示。** 相同输入重复一致，不代表判断正确。当前不支持将模型直接用于可靠的面色辨证或疾病确诊。

研究路线建议优先 **Route B：Face CV + ShizhenGPT-VL 的受控验证**。Face CV 的第一任务应是图像质控、可见区域判断、定位和颜色测量，而非直接建立疾病分类器。Route A 保留为对照基线；现有证据不足以立即投入 Route C。当前阶段未实现任何专用 CV。

## 实验范围与方法

官方 TCM-Vision-Benchmark 的 JSON 和图片 ZIP 均通过 SHA256 校验。实际数据包含 7,204 道题，其中 Tongue 768 道。开放式舌象使用 3249、3376、3263、3912；另外选择 3245、3248 进行选择题对照。选择过程是按标签筛选后的少量工程样本，并非随机、独立的临床测试集。

该评测集的面部相关条目主要为投影示意图与局部照片，不能构成真实面色评测集。面诊主样本采用 scikit-image 保存的 NASA Eileen Collins 公开照片，手工裁剪 `(150,20,305,192)`，无医学标签，健康状态未知。局部面部样本 5467 和示意图 4923 用作可见区域与负面对照。图文联合中的症状为实验构造，不是照片人物的真实自述。

| 测试组成 | 推理次数 |
|---|---:|
| 主评测：舌象、面部、成像变化、文本、图文对照、反幻觉、原始选择题 | 75 |
| 补充：纯视觉提示、视觉优先图文提示及无图对照 | 24 |
| 同一题目的三种选项循环换序 | 18 |
| **正式评测合计** | **117** |

另执行一次 Smoke Test，以及一次预热和三次独立性能测试。正式评测默认 `do_sample=False`、`max_new_tokens=768`、seed 42，保留权重自带 `repetition_penalty=1.05`。temperature/top_p/top_k 在非采样模式下不生效。图像像素上限 1,003,520；公开人脸裁剪分辨率只有 155×172，细节能力受到限制。未测试 sampling 模式，也不将当前重复性外推到 sampling。

31 组代表性条件各真实运行 3 次，组内完整字符串全部一致。选择题使用单次生成并执行选项换序，以检查顺序偏差。

## 舌诊：基础能力存在，细节和措辞不够可靠

- **舌质**：4 个开放式样本多被描述为淡红、略胖大。存在模板化倾向，未有专业人工标注来验证细粒度舌质判断。
- **舌苔**：3376 能描述为黄色；3249 描述为少量淡白 / 极薄，且表达不确定。图文联合时，同一黄苔图又被描述为“白厚腻，中部偏黄”，说明症状条件会影响视觉表述。
- **齿痕**：多个样本都被描述为轻微齿痕，不能据此认定可靠。3912 对选择题顺序敏感，四种顺序仅答对一次。
- **裂纹**：3263、3376 的回答同时出现“未见明显裂纹”和“轻微纵向裂纹”，观察力度和措辞需审阅，尚不能确认为可靠裂纹检测。
- **观察 / 解释分离**：3263 在“视觉观察”中加入热象、血瘀、脾虚推断，未严格遵守来源分层。该样本的三次输出还包含 Unicode 替换字符，已保留原文，原因未进一步定位。

### 选择题与顺序控制

最初 6 题答对 5 题，但全部选 B，恰好等于“恒选 B”基线。追加同一题目的 3 种选项循环换序后，新增 18 条件答对 9 条；合并 24 条件答对 14 条，平衡后的恒选任一固定字母基线为 6/24。

| 图片 ID | 标签摘要 | 四种顺序答对次数 |
|---|---|---:|
| 3245 | 厚苔 | 2/4 |
| 3248 | 薄苔 | 2/4 |
| 3249 | 白色舌苔 | 1/4 |
| 3263 | 薄苔 | 4/4 |
| 3376 | 黄色舌苔 | 4/4 |
| 3912 | 舌质淡、舌边齿痕 | 1/4 |

14/24 是这 6 张选定教材图片的 24 个题目条件结果，不是 24 个独立样本，不是完整官方 benchmark 成绩，更不是医学诊断准确率。训练数据重叠、教材标签质量和临床泛化均未排除。

## 面诊与 Lighting Robustness

原图、亮度 ×1.15、亮度 ×0.85、RGB 偏黄 `[1.08,1.02,0.88]`、RGB 偏蓝 `[0.88,1,1.08]`、Gaussian blur 0.8 和 JPEG quality 35 共 7 条件，各运行 3 次。只改变像素成像条件，不改变面部几何。RGB 乘数是人工扰动，不是已标定的物理色温变化。

| 项目 | 观察 |
|---|---|
| 整体面色 | 原图称“肤色均匀”；调亮称“黄白”；偏蓝也称“黄白” |
| 光泽 / 唇色 | 通常描述轻微光泽、淡红或淡粉唇色，缺少标定参考，未验证可靠性 |
| 左右 / 局部 | 调亮前后左右明暗表述变化；不同条件下鼻部正常与发红等描述变化 |
| 中医解释 | 调亮后增加脾胃虚弱、肝郁、肺胃热等可能解释；模型虽然提示成像限制，仍对成像变化作生理引申 |
| 局部图 5467 | 无年龄文字，实际只见局部脸颊与耳部；却写“11岁女性”，并补全鼻、唇、另一侧脸颊等不可见信息 |
| 面部示意图 4923 | 能识别理论示意图，说明无法进行真实面色分析 |

工程结论：面色、光泽、唇色、局部区域均未达到可确认的可靠水平。结果证明描述对人工成像扰动敏感，**不能证明模型还原了人的真实面色，也不能单凭此实验断言它只识别色温**。没有多人物、标定色卡、真实健康标签或受控拍摄序列。

禁止中医推断的补充纯视觉提示能抑制脏腑和证候引申，但输出转为大量“无法判断”，且出现“静态照片无法判断明暗”等不充分理由；没有证据表明仅改提示就解决了面色测量问题。

## 问诊、反幻觉与图文联合

**纯文本问诊**：能给出可能解释和追问，不足信息输入“有点累”时能直接回答信息不足。但完整输入的“睡眠质量一般”被反复改为“睡眠质量差”，并引入“睡眠浅”等原文没有的表述。信息忠实度不够严格。

**反幻觉**：显式要求证据不足时说不足，可使几何图形、公开人脸、普通舌象对照都拒绝直接辨证。这说明提示有明显作用；不代表所有提示条件下都安全。Smoke Test 的无关图形五行引申、局部脸部的不可见信息补全和无图对照的虚构观察仍存在。

**原图文提示**：相同四条症状分别搭配无图、人脸、白苔、黄苔、几何图形。所有有图条件实际都有 `pixel_values` 与 `image_grid_thw`，但回答仍称“未提供图片 / 舌象”，主要依据症状文本作答。

**视觉优先提示**：改为先问“图片中有哪些直接可见的特征”，再分析同一组症状。人脸、白苔和黄苔回答开始包含不同视觉内容；黄苔条件也解释了苔色与寒湿判断的矛盾。这是视觉输入影响联合回答的证据。不过视觉描述也随症状条件改变，并反复改写睡眠程度；无图对照则虚构“面色偏白、淡红舌、薄白苔、手部苍白”等观察。

结论：技术上 Vision 与 Text 均进入模型，部分提示下可见图像影响；**尚未证明可靠的语义融合和来源忠实度**。默认联合提示的失效不能简单归为没有图像通道，也不能把换提示后的流畅解释当作融合已经可靠。

## 后续路线与边界

**Route A — ShizhenGPT-VL directly**：适合继续做研究、客观图片描述和问诊辅助草稿，需来源核对与人工审阅。当前结果不支持直接使用开放式面诊辨证输出。

**Route B — Face CV + ShizhenGPT-VL**：本次优先建议的验证方向。先采集多人物、固定光照与白平衡、无美颜、含色卡的授权照片；验证曝光 / 模糊 / 遮挡质控、可见区域与左右定位、面部区域颜色及光泽量化，再比较是否降低面色漂移与不可见区域补全。需同时限制语言模型无依据推断，Face CV 本身不会修复症状改写或理论幻觉。

**Route C — Face CV + Tongue CV + ShizhenGPT**：目前没有足够独立标注数据、模块对照或错误归因证据来支持这一步。应先验证 Route B 的收益，并扩大舌象标注与换序测试，再判断是否需要专用 Tongue CV。

未开展微调、LoRA、RAG、Agent、知识图谱、量化或专用 CV。医学诊断准确率、临床安全性、不同人群泛化与医疗知识正确性未被本轮工程评测证明。
